How to use it

  1. 1 Go to ChatGPT, Claude, or Gemini and have a conversation.
  2. 2 Click the Export Chat bookmark in your bookmarks bar. A new tab opens.
  3. 3 The first time, you'll be asked for your OpenAI API key. Enter it — it's saved in your browser so you won't need to enter it again.
  4. 4 Your conversation is summarised and a shareable link is generated. Copy it and send it to anyone.

Questions

Will the URL ever expire?

No. There's no server storing your data — it's all encoded directly in the URL itself. The link will work as long as this page exists at its address (for example, on GitHub Pages).

Is my API key safe?

Your key is entered on the export page and saved only in your browser's localStorage. It's never sent to any server we control — only to api.openai.com to generate the summary. You can open DevTools → Network and verify this yourself.

What if the URL is too long to share?

Short and medium conversations compress well. Very long conversations may produce long URLs that some apps truncate when pasted. If that happens, use your browser's Print → Save as PDF to share a file instead.

Can I see the full conversation, not just the summary?

Yes — the viewer page has a "View full conversation" section that shows every message. It's collapsed by default to keep the summary front and centre.

Which AI tools are supported?

ChatGPT, Claude.ai, and Gemini are supported with dedicated extractors. Any other page will fall back to a generic text extraction, which may be less accurate.
